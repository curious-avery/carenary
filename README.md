# Carenery — GitHub Pages build

This folder is the ready-to-upload static build for:

`https://curiousavery.github.io/carenery/`

## Deploy

1. Open the `curiousavery/carenery` repository on GitHub.
2. Upload **the contents of this folder**, not the enclosing folder or ZIP.
3. Confirm `index.html` appears at the repository root.
4. In **Settings → Pages**, choose **Deploy from a branch**, the repository's
   publishing branch (normally `main`), and `/(root)`.
5. Save and allow up to 10 minutes for the deployment.

This is a buildless static application. It was exported from the current
hosted Sites source at commit `7f1e610e569c05ca5084dc973d1a637f60a801f6`.
Its assets use safe relative URLs so it works beneath the `/carenery/` project
path. The live ClinicalTrials.gov and CMS lookups still require an internet
connection in the visitor's browser.
